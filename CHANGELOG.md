## v0.9.1 - 2026-01-04
### Added
* Registration: users get API key immediately. Approval is optional (serve setting)
* Added a limit to the # of races per user, (configurable with RACE_LIMIT_PENDING, RACE_LIMIT_APPROVED)
* Added a limit to the number of sessions a user can join/create (configured with 'SESSION_MEMBERSHIP_LIMIT')
* New endpoint POST /v1/sessions/{session_id}/archive to archive finished sessions. Only session managers can archive.
* New 'include_archived' query parameter on GET /v1/sessions to optionally include archived sessions (default false).
* New serve option --autocreate-admin (NEPER_SERVE_AUTOCREATE_ADMIN) to automatically create an admin user on startup if it doesn't exist. Simplifies first-time setup.
### Changed
* Updated houston dependency to v0.2.0
* Replace session 'started' boolean with 'state' enum (pending, started, archived). Archived sessions are not joinable and don't count towards session membership limits.
