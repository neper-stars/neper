## v0.10.0 - 2026-01-06
### Added
* Add bot support to sessionplayerraces
* Added a new handler to allow removing a SessionPlayerRace. Admins can remove bots and players. Players can remove themselves. A player must not be ready.
* Added the id in the SessionPlayerRace to allow easy deletion from client side
### Changed
* Remove unique constraint on players per session to allow multiple bots (system user) on a single session
* The sessionPlayer request now returns an optional race name when the player is a bot
* Bots are now always ready in a session and only players needs to be not ready to be changed (allowing admin to modify bots even when ready)
* Change game start to avoid multiple start attempts
